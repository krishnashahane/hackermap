# Security Policy

## Scope

HackerMap is a static, browser-only simulation. It does not collect telemetry, accept accounts, operate a backend, or interact with target networks.

## Reporting a vulnerability

Please report suspected security issues through GitHub's private vulnerability reporting feature for this repository when available. Avoid publishing exploit details in public issues until a fix is available.

Include the affected file, browser/runtime details, reproduction steps, and the potential impact. Do not include real credentials, personal information, or live target data.

## Supported versions

Security fixes are applied to the latest version on the default branch.
